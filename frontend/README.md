# Frontend

React-based frontend for the 3D Engineering Model Generator.

## Features

- Interactive model configuration form
- Real-time 3D preview using Three.js
- Model export in multiple formats (GLB, glTF, OBJ)
- Responsive design

## Project Structure

- `src/pages/` - Page components
- `src/components/` - Reusable UI components
- `src/services/` - API service layer
- `src/utils/` - Helper functions and utilities

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
